## Remaining release blockers

DAF must not advertise a production autonomous distributed system until these requirements have executable evidence:

1. **Integrated authenticated dispatcher:** runtime startup still does not compose transports, authorization, routing and workers into a managed cluster. Handshake helpers expose credentials; applications must verify identities and permissions. The test token gate is a fixture.
2. **Distributed delivery semantics:** no demonstrated durable queue, restart replay, deduplication/idempotency, exactly-once effects, consensus or network-partition recovery.
3. **Model capability evaluation:** no integrated model provider, held-out task suite, calibrated uncertainty, reproducible learning or demonstrated improvement. There is no basis for AGI/ASI assertions.
4. **Memory correctness at scale:** substring/full-scan retrieval and heuristic Jaccard consolidation; no embeddings or learned memory. Independent managers can race metadata writes; no cross-record transactional consolidation. Lossy merging needs stronger evidence-preservation policy.
5. **Authorization and secret handling:** vault access is a trusted operator API; stored policies are not a verified caller boundary. Retrieved secret objects can hold serializable plaintext. Application code must avoid persisting/logging those values.
6. **Persistence fault testing:** explicit Sled flush is available, but graceful reopen does not prove power-loss behavior; no crash/failure-injection harness ran. RocksDB/Sled/logger/vault lack one unified transaction boundary.
7. **Operations:** configuration/provision providers largely describe changes; unsupported CLI apply/cluster paths remain unsupported. Retention maximum-entry/archive behavior and detached subprocess lifecycle need additional design and tests.
8. **Performance evidence:** benchmark sources compile under strict checks, but no measured throughput, latency, recall quality or capacity results establish production budgets. The declared Rust 1.85 minimum was not independently verified with that compiler.

Prioritize authenticated local integration and durable delivery before new intelligence claims. Then add fault injection, bounded/indexed evidence memory, explicit human approval policies and held-out autonomous-task evaluation. Each step must satisfy the standard on its actual execution path.
